# ❤️ Python Animated Heart

A small Python application that creates an animated heart with sound effects.

The project combines a Python application with audio files to create a simple visual and audio animation experience.

---

## ✨ Features

- ❤️ Animated heart
- 🔊 Heart sound effect
- 🖱️ Click sound effect
- 🎵 Audio integration
- 🐍 Built with Python
- 📦 Includes an application specification file
- 🎨 Simple interactive animation

⚙️ Requirements

You need Python 3 to run the source code.

Check your Python installation:

python --version

or:

python3 --version
🚀 Running the Application

Clone the repository:

git clone https://github.com/namankarna0/Python_Heart.git

Enter the project directory:

cd python-animated-heart

Run the application:

python app.py

On Linux:

python3 app.py
🔊 Audio Files

The application uses two .wav files:

heart.wav

Used as the heart-related sound effect during the animation.

click.wav

Used for click/interaction feedback.

Make sure both files remain in the expected project directory when running the application.

app.py
click.wav
heart.wav

Moving or renaming the audio files may cause the application to fail to find them.

📦 Application Specification

The project also contains:

app.spec

This file can be used as a specification/configuration file when packaging the Python application into a standalone executable, depending on the packaging setup used by the project.
